\section{Objetivos de la sesion}
Presentar las bases del documento y la asignación de roles dentro del equipo. El proyecto sera la creación de un asistente inteligente de voz, programado íntegramente en Python.

El objetivo es diseñar un agente que pueda:
\begin{itemize}
    \item Escuchar y procesar comandos de voz (Speech-to-Text).
    \item Comprender la intención del usuario (Natural Language Processing).
    \item Tomar decisiones y ejecutar acciones basadas en esa intención (Lógica del Agente).
    \item Proporcionar retroalimentación audible (Text-to-Speech).
\end{itemize}

\subsection{Acuerdos de Tareas para el equipo:}
La carga de trabajo se distribuye de la siguiente manera:

\textbf{Victor (Líder y NLP)}
\begin{itemize}
    \item \textbf{Gestión de Repositorio:} Configurar y mantener el repositorio de GitHub, gestionar las ramas (branches) y fusiones (merges). **Con ayuda de Perci".
    \item \textbf{Módulo de NLP (Natural Language Processing):} Desarrollar el componente central que recibe el texto transcrito por Victor. (Dependiendo del analisis que podra tener las API de OpenIA)
    \item \textbf{Responsabilidad Clave:} Usando librerías como \texttt{spaCy} o \texttt{NLTK}, deberá extraer la \textbf{intención} del usuario (e.g., "buscar", "reproducir", "preguntar") y las \textbf{entidades} (e.g., "clima en CDMX", "canción de X").
\end{itemize}

\textbf{Percival (Módulo de Speech-to-Text - STT)}
\begin{itemize}
    \item \textbf{Módulo STT (Reconocimiento de Voz):} Implementar el componente que escucha activamente el micrófono.
    \item \textbf{Librerías:} Investigar e implementar la librería más adecuada (e.g., \texttt{SpeechRecognition}) para capturar el audio y transcribirlo a una cadena de texto.
    \item \textbf{Activación:} Investigar la implementación de una "palabra de activación" para que el asistente no escuche permanentemente.
\end{itemize}

\textbf{Angel (Módulo de Text-to-Speech - TTS)}
\begin{itemize}
    \item \textbf{Módulo TTS (Síntesis de Voz):} Desarrollar el componente que le da "voz" al asistente.
    \item \textbf{Librerías:} Recibirá una cadena de texto (la respuesta del asistente) y usará una librería (e.g., \texttt{pyttsx3}, \texttt{gTTS}) para sintetizarla en audio y reproducirla.
\end{itemize}

\textbf{Adolfo (Lógica del Agente y Acciones)}
\begin{itemize}
    \item \textbf{Núcleo Lógico (Cerebro):} Diseñar e implementar el "cerebro" del asistente.
    \item \textbf{Sistema de Reglas/Decisión:} Recibirá la "intención" y las "entidades" del módulo NLP de Percival.
    \item \textbf{Responsabilidad Clave:} Implementará la lógica (usando un sistema de reglas, \texttt{if-elif-else}, o un árbol de decisión) para determinar \textbf{qué acción} debe ejecutar el asistente.
    \item \textbf{Codificación de Acciones:} Programará las acciones básicas (e.g., responder a un saludo, decir la hora).
\end{itemize}

\textbf{Rodrigo (Documentación Técnica y Teórica)}
\begin{itemize}
    \item \textbf{Responsable de Documentación:} Se encargará de toda la documentación escrita del proyecto.
    \item \textbf{Entregable de Teoría:} Redactar el ensayo en LaTeX sobre los modelos de IA, para que sea como los requisitos del proyecto.

\end{itemize}
